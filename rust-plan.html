Badges

How each day works

  • Review (15 min): close the book. Explain yesterday's topic, last week's topic and last month's topic aloud, then re-type one small example from memory.
  • Learn (50 min): read the section, type every example yourself, and try to break it.
  • Practice (45 min): exercises or the current mini project. Read the compiler error twice before searching.
  • Log (10 min): three things learned, one error you met, one question for tomorrow.
  • Missed a day? Don't double up. Do that day's review and the next topic, then tick the missed day only when you've really finished it.
Resources: The Rust Programming Language (doc.rust-lang.org/book), Rustlings, Exercism Rust track, Rust by Example.
