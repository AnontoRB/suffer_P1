Badges

How this plan stays efficient

  • Learn by doing, not watching. Roughly 40% reading, 60% writing code. No long video courses.
  • Three resources do almost everything: The Rust Book (the main text), Rustlings (small exercises, run in your terminal), and the Exercism Rust track (problems with feedback). Later you add the Tokio tutorial and axum docs.
  • Fight the compiler on purpose. Read every error message fully. Rust's errors teach you the language.
  • Type all code yourself. Never copy and paste.
  • Keep a notes file (notes.md) with one line per new concept and every mistake you made. Review it on checkpoint days.
  • Commit all your code to Git daily. One folder per project.

Every day has 3 parts (2 hours)

PartTimeWhat
1. Learn45 minRead the assigned section and type out every example
2. Practice45 minRustlings or Exercism exercises on the same topic
3. Build/Review30 minApply it in a small program, or review notes

Marathon tip: on run days, do Part 1 before your run and Parts 2 and 3 after, or vice versa. Do not skip the study on rest days. That is when you get your full 2 hours in one block.

Setup (do first, today): install Rust with rustup, install VS Code with the rust-analyzer extension, and install Rustlings (cargo install rustlings).

If you fall behind

  • Do not double up. Skip the Part 3 review first, then Part 2, but never skip Part 1.
  • If a chapter takes 2 days, repeat it, then drop one Exercism day later.
  • If the borrow checker has you stuck for more than 30 minutes, read the error again, simplify the code, and ask for help. Pasting the code and error is the fastest fix.

After Jan 6: how to keep going

  • Contribute small fixes to an open-source Rust project (look for good first issue).
  • Read Rust for Rustaceans and Programming Rust.
  • Build one larger project in an area you like: CLI tools, web backends, embedded, games, or systems.
  • Do 1 to 2 Exercism problems a week to stay sharp.
Resources: The Rust Book, Rustlings, Exercism Rust track, Rust by Example, Tokio tutorial, axum docs.
