HOW TO OPEN THIS SITE

Put ALL of these files together in one empty folder:

  index.html   rust.html   marathon.html   health.html   cubing.html   styles.css
  common.js    settings.js  home.js     rust-data.js    rust.js
  marathon-data.js         marathon.js
  health-data.js           health.js
  cubing-data.js           cubing.js

Then double-click index.html to open it in your browser.

Delete any old copies first (for example fitness.html, fitness.js, fitness-data.js).
